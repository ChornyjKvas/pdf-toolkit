# Roadmap

Foundation: responsive homepage, honest placeholders, static-friendly routing, and automated checks.

1. Browser-only PDF merge: implemented with pure functions, invalid-file handling, ordering, local downloads, resource cleanup, and synthetic tests.
2. PDF split with page-range validation.
3. Rotate and delete pages, with clear selection and error handling.
4. Visual page organizer; evaluate PDF.js when previews are needed.
5. Public deployment after hosting, accessibility, resource-limit, and privacy verification.

Current status: Merge PDF is available. Split, Rotate, and Delete Pages remain coming soon. No server upload, document storage, accounts, analytics, or monetization exists. Next implementation scope should be specified separately.
