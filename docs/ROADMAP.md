# Roadmap

Foundation: responsive homepage, honest placeholders, static-friendly routing, and automated checks.

1. Browser-only PDF merge: implemented with pure functions, invalid-file handling, ordering, local downloads, resource cleanup, and synthetic tests.
2. Browser-only PDF split: implemented with ordered extraction, separate outputs, strict page-range validation, local downloads, cleanup, and synthetic tests. ZIP convenience is deferred.
3. Rotate and Delete Pages: implemented with validated selections, retained original order/geometry, local downloads, cleanup, and synthetic tests. Delete refuses empty output in the UI and PDF operation.
4. Visual page organizer; evaluate PDF.js when previews are needed.
5. Public deployment after hosting, accessibility, resource-limit, and privacy verification.

Current status: all four essential tools are available. No server upload, document storage, accounts, analytics, or monetization exists. The visual page organizer is a future milestone requiring a separate specification; it has not been started.
